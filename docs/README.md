# 听潮文档导航

听潮是 VMusic 仓库中的 Vue 3 音乐 Web 应用。这里同时保留当前项目文档、
参考项目分析与课程汇报资料，原有文件名保持不变。

当前实现说明于 2026-10-12 对照源码整理。功能以实际页面和代码为准；
文档中的验收步骤是检查方法，不代表所有流程都已通过真人验证。

## 第一次了解或运行项目

1. 阅读[项目 README](../README.md)，了解功能、环境要求与 Vercel 部署方式。
2. 按[API 启动说明](./NeteaseAPI启动说明.md)启动前后端并检查接口。
3. 查看[功能状态与待办](./VMusic待办事项清单.md)，了解目前可用的入口和限制。

## 文档职责与维护约定

- README 负责项目入口、安装和部署，不复制整份设计报告。
- 架构文档描述代码组织与执行链路；功能文档描述用户操作和数据去向。
- 需求文档保留可验收的条件，待办文档记录状态与尚未解决的问题。
- 参考分析描述对应的上游源码快照，不表示听潮具有参考项目的全部功能。
- 汇报中的姓名、分工、截图、环境和实测结果由提交者补充，不能用占位内容冒充完成材料。

改动页面、接口或缓存时，同步更新对应文档与源码链接。
依赖版本以 [package.json](../package.json) 和锁文件为准，
路由以 [src/router/index.js](../src/router/index.js) 为准，
默认值与缓存参数以 [src/constants.js](../src/constants.js) 为准。
