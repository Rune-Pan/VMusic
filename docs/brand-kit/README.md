# 听潮品牌套件 · B「潮·水势」

已选定的原创品牌方向：以「潮」的三点水和三笔潮线融合声音节奏。几何与三方向预览中的 B 完全一致，未再调整造型。

## 文件与使用

- `brand-mark.svg`：32×32 母形，描边 2.5，继承 `currentColor`。用于站内导航 22px、登录区域 40px 等常规尺寸。
- `brand-mark-small.svg`：同母形的小尺寸简化版，描边 3。用于 16px 单色符号。
- `app-icon.svg`：256×256 蓝白应用图标，底色 `#3b82f6`，四周透明留白。
- `favicon.svg`：蓝白底板与简化图形，用于 16px 场景。
- `png/icon-{size}.png`：16、24、32、48、64、128、256、512px；16px 来自简化版，其余来自标准应用图标。
- `favicon.ico`：包含 16、32、48px 三个独立 PNG 帧，16px 使用简化版。
- `app-icon.ico`：包含 16、24、32、48、64、128、256px 七个独立 PNG 帧，供 Windows 应用使用。

站内 SVG 应内联或封装为品牌组件，才能继承网站强调色；通过 `<img>` 加载外部 SVG 不会继承父元素的 `currentColor`。导航继续使用 30px 容器，登录页使用 88px 容器，保留现有「听潮」文字。

favicon 与桌面图标始终固定蓝白。不要用标准大图直接缩出 16px，也不要把底板玻璃化；站内玻璃材质由容器提供。
