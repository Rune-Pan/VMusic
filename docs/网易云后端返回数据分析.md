# 网易云音乐后端可返回数据分析报告

> 分析对象：听潮 项目中通过 NeteaseCloudMusicApi 调用的所有后端接口
> 后端地址：`http://localhost:3000`（第三方库 NeteaseCloudMusicApi 独立服务）
> 前端代理：`/api` → `http://localhost:3000`（见 `vite.config.js`）

---

## 一、整体架构

```
┌────────────┐   /api/xxx    ┌────────────────────────┐   HTTP    ┌──────────────┐
│ Vue 前端   │ ────────────> │ Vite Dev Proxy         │ ────────> │ NeteaseCloud │
│ (本仓库)   │ <──────────── │ /api → localhost:3000  │ <──────── │ MusicApi     │
└────────────┘               └────────────────────────┘           └──────────────┘
```

- **请求封装**：`src/utils/request.js`（axios 实例，`baseURL=/api`，`withCredentials=true`，15s 超时）
- **响应处理**：拦截器直接返回 `response.data`；`code===301` 且 `msg==='需要登录'` 时提示登录过期
- **API 模块**：`src/api/` 下 5 个文件（auth / user / playlist / track / others）

## 二、所有接口与可返回数据清单

### 1. 认证模块（`src/api/auth.js`）

#### 1.1 手机号登录 `POST /login/cellphone`
- **请求参数**：`{ phone, password }`
- **返回数据**：
  ```jsonc
  {
    "code": 200,
    "account": { "id": 123456, "userName": "xxx" },
    "profile": {
      "userId": 123456,
      "nickname": "昵称",
      "avatarUrl": "https://...",
      // ...其他用户资料字段
    }
  }
  ```
- **项目消费字段**：`code`、`profile.userId`、`profile.nickname`、`profile.avatarUrl`、`account.id`、`account.userName`

#### 1.2 邮箱登录 `POST /login`
- **请求参数**：`{ email, password }`
- **返回数据**：同 1.1

#### 1.3 二维码登录密钥 `GET /login/qr/key`
- **请求参数**：`{ timestamp }`
- **返回数据**：
  ```jsonc
  { "code": 200, "data": { "unikey": "xxx-xxx-xxx" } }
  ```

#### 1.4 二维码生成 `GET /login/qr/create`
- **请求参数**：`{ key, timestamp }`
- **返回数据**：
  ```jsonc
  { "code": 200, "data": { "qrimg": "data:image/png;base64,...", "qrcode": "https://music.163.com/login?codekey=xxx" } }
  ```

#### 1.5 二维码状态检查 `GET /login/qr/check`
- **请求参数**：`{ key, timestamp }`
- **返回数据**：
  ```jsonc
  { "code": 803, "cookie": "MUSIC_U=xxx;;__csrf=xxx;;...", "message": "..." }
  ```
- **code 含义**：`800`=二维码过期 / `801`=等待扫码 / `802`=待确认 / `803`=登录成功
- **项目消费字段**：`code`、`cookie`（成功后写入 document.cookie + localStorage）

#### 1.6 登出 `POST /logout`
- **返回数据**：`{ "code": 200 }`

### 3. 歌曲/音轨模块（`src/api/track.js`）

#### 3.1 获取播放 URL `GET /song/url`
- **请求参数**：`{ id, br }`（br=码率，默认 320000）
- **返回数据**：
  ```jsonc
  {
    "code": 200,
    "data": [
      {
        "id": 123,
        "url": "http://m801.music.126.net/xxx.mp3",
        "br": 320000,
        "size": 12345678,
        "type": "mp3",
        "md5": "abc123...",
        "level": "exhigh",
        "expi": 1200,
        "freeTrialInfo": null,    // 非 null 表示试听片段
        "freeTrialPrivilege": { ... },
        "code": 200,
        "fee": 8,
        "uf": null,
        "payed": 1,
        "flag": 4
      }
    ]
  }
  ```
- **项目消费字段**：`data[0].url`（强制 https）、`data[0].freeTrialInfo`（非 null 跳过试听）

#### 3.2 歌曲详情 `GET /song/detail`
- **请求参数**：`{ ids }`（逗号分隔的 ID）
- **返回数据**：
  ```jsonc
  {
    "code": 200,
    "songs": [
      {
        "id": 123,
        "name": "歌曲名",
        "ar": [ { "id", "name", "tns": [], "alias": [] } ],   // 歌手
        "al": { "id", "name", "picUrl", "tns": [], "pic": 0 }, // 专辑
        "dt": 234567,                  // 时长(ms)
        "fee": 8,                      // 0 免费 / 1 VIP / 4 购买 / 8 试听
        "mv": 12345,                   // MV ID
        "no": 3,                       // 专辑内曲号
        "tn": null,                    // 翻译名
        "publishTime": 1234567890000,
        "copyrightId": 0,
        "mark": 0,
        "originSongDataType": 0,
        "privilege": { /* 见下 */ }
      }
    ],
    "privileges": [
      {
        "id": 123,
        "fee": 8,
        "pl": 320000,                 // 当前可用码率（0=不可播）
        "cs": false,                  // true=无版权
        "maxbr": 999000,
        "fl": 320000,
        "dl": 320000,
        "st": 0,
        "subp": 1,
        "cp": 1,
        "downloadMaxbr": 999000,
        "playMaxbr": 999000,
        "rightSource": 0,
        "toast": false
      }
    ]
  }
  ```
- **项目消费字段**：
  - 歌曲侧：`id`、`name`、`ar[].name`、`al.name`、`al.picUrl`、`dt`、`privilege`
  - 权限侧：`privilege.pl`（=0 需 VIP）、`privilege.cs`（true 无版权）、`privilege.fee`（=4 需购买）
  - `mapTrackPlayableStatus()` 自动注入 `playable` 和 `reason` 字段

#### 3.3 歌词 `GET /lyric`
- **请求参数**：`{ id }`
- **返回数据**：
  ```jsonc
  {
    "code": 200,
    "lrc":    { "version": 6, "lyric": "[00:01.00]原词..." },          // 原文歌词
    "tlyric": { "version": 1, "lyric": "[00:01.00]翻译..." },          // 翻译歌词
    "klyric": { "version": 1, "lyric": "[00:01.00]..." },              // 卡拉OK逐字
    "romalrc":{ "version": 1, "lyric": "[00:01.00]拼音..." },          // 罗马音歌词
    "yrc":    { "version": 2, "lyric": "{...逐字逐句JSON...}" },        // 新版逐字歌词
    "ytlrc":  { "version": 1, "lyric": "..." },                        // 逐字翻译
    "qfy": false,
    "point": 0,
    "isNowPlaying": false,
    "costScore": false
  }
  ```
- **项目消费字段**：仅 `lrc.lyric`（通过 `parseLRC()` 转为 `{time, content}[]`）
- **未被使用的字段**：`tlyric`（翻译）、`klyric`（卡拉OK）、`romalrc`（罗马音）、`yrc`（逐字歌词）— 可用于扩展翻译歌词/逐字动效

#### 3.4 听歌打卡 `GET /scrobble`
- **请求参数**：`{ id, sourceid, time, timestamp }`
- **返回数据**：`{ "code": 200, ... }`

## 三、关键数据结构：歌曲对象（Song）

这是几乎所有接口都会返回的核心对象，字段定义：

| 字段 | 类型 | 含义 |
|------|------|------|
| `id` | number | 歌曲 ID |
| `name` | string | 歌曲名 |
| `ar` | array | 歌手列表 `[{id, name, tns, alias}]` |
| `al` | object | 专辑 `{id, name, picUrl, tns, pic}` |
| `dt` | number | 时长（毫秒） |
| `fee` | number | 0=免费 / 1=VIP / 4=购买 / 8=试听 |
| `mv` | number | MV ID |
| `no` | number | 专辑内曲号 |
| `tn` | object\|null | 翻译名 |
| `publishTime` | number | 发布时间戳 |
| `copyrightId` | number | 版权 ID |
| `mark` | number | 标记位 |
| `privilege` | object | 播放权限对象（见下） |
| `reason` | string | 项目注入：'' / '无版权' / '需购买' / '需 VIP' |
| `playable` | boolean | 项目注入：是否可播放 |

## 四、关键数据结构：权限对象（Privilege）

| 字段 | 类型 | 含义 |
|------|------|------|
| `id` | number | 歌曲 ID |
| `fee` | number | 0/1/4/8（同上） |
| `pl` | number | **当前可用码率，0=不可播（需 VIP）** |
| `cs` | boolean | **true=无版权** |
| `maxbr` | number | 最大码率 |
| `fl` | number | 免费码率 |
| `dl` | number | 下载码率 |
| `st` | number | 状态 |
| `subp` | number | 子版权 |
| `cp` | number | 版权类型 |
| `downloadMaxbr` | number | 下载最大码率 |
| `playMaxbr` | number | 播放最大码率 |
| `rightSource` | number | 权限来源 |
| `toast` | boolean | 是否提示 |

**项目可播放判断逻辑**（`src/utils/common.js`）：
```javascript
function isTrackPlayable(track) {
  if (!track?.privilege) return true
  const privilege = track.privilege
  if (privilege?.pl === 0 || privilege?.cs || privilege?.fee === 4) return false
  return true
}
```

## 七、总结

本项目共调用 **17 个网易云后端接口**，覆盖：登录认证、用户信息、歌单管理、歌曲播放/详情/歌词、搜索、推荐、排行榜、播放历史、私人 FM 等核心功能。

**后端可返回但项目未消费的数据**主要集中在：
1. **歌词增强**：翻译歌词、逐字歌词、罗马音歌词（可直接接入做双语/逐字动效）
2. **MV 数据**：通过 `mv` ID 调用 `/mv/detail` 获取 MV 播放地址
3. **社交数据**：歌单订阅/评论/分享数、推荐理由
4. **用户详情**：等级、注册天数等
5. **多类型搜索**：专辑、歌手、歌单搜索

这些数据后端已经能返回，只需在前端添加消费逻辑即可扩展功能。
