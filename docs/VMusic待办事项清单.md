| 能力             | 当前边界                                                                    |

| 歌单信息编辑     | Store 的 `updatePlaylist()` 修改本地记录，没有服务端编辑接口和界面入口      |
| 歌单内移除歌曲   | 详情页更新当前列表和本地记录，没有调用 `/playlist/tracks` 删除服务端歌曲    |
| 歌单简介同步     | 创建表单有简介字段，但创建接口只提交名称和隐私参数；简介保存于本地          |
| 个人资料修改     | 保留 `updateProfile()` 和 `/user/update` 封装，设置页没有昵称、头像修改入口 |
| 收藏歌单         | 可以展示账号已有收藏歌单；收藏 / 取消收藏按钮与前端接口封装已移除           |
| 专辑详情         | 可以搜索专辑、查看歌手的专辑列表；尚无独立专辑页                            |
| 注册、邮箱登录   | 当前只登录已有网易云账号，没有注册或邮箱登录入口                            |
| 私人 FM、MV      | 没有对应页面，前端也未保留私人 FM 调用函数                                  |
| 评论发表         | 只有查看，没有输入和提交功能                                                |
| 移动端与离线音频 | 当前以桌面为目标；不保存音频文件，不提供离线播放                            |

## 已知接口问题的记录方式

过去对 `/playlist/subscribe` 的调用曾得到 405，前端随后移除了收藏操作。
已有排查记录涉及账号、请求通道和请求频率，但未确定上游具体校验机制。
这是一条历史现象，不能推广为“所有账号都不可用”或“其他接口永远正常”。
恢复该功能前，记录复现日期、环境、接口参数和响应，再对照后端模块及上游变更。
错误码本身不足以证明唯一原因。

## 代码中保留的保护机制

- 音量静音前保存原音量，取消静音时恢复。
- 喜欢列表变更后持久化；请求正在进行时合并拉取，减少状态覆盖。
- 播放列表使用副本，避免直接修改喜欢列表的数据引用。
- 音频加载失败后清除该曲目 URL 缓存，最多重取一次。
- 播放队列删空时停止音频和进度计时器。
- 播放页保持固定全屏，视图保持单根以适配路由过渡。
- 搜索结果在路由变化时关闭；歌手结果跳详情，专辑结果提示暂不支持详情。

后续修改这些逻辑时，应按[验收清单](./需求规格说明书.md#验收清单)复核相关操作。
