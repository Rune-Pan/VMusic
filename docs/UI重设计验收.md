# 听潮桌面 Liquid Glass 重设计验收

日期：2026-10-19。源码位于当前工作区；本轮不重新生成安装包、不发布、不推送。

## 本地预览

生产预览：[http://127.0.0.1:4173/](http://127.0.0.1:4173/)。API 使用本地 3000 端口。未登录时按原有路由规则进入登录页；三种登录方式保留。浏览器验收数据来自独立自动化上下文，未写入日常浏览器或真实账户。

## 已完成的界面

- 全部八个路由使用新的桌面视觉系统。带文字的左导航、顶部搜索/主题/账户、底部共享悬浮播放器统一布局。
- 首页首项推荐成为重点封面，其余按原顺序进入网格；每日推荐、排行榜、歌单和歌手页统一封面与歌曲层级。个人中心使用横向标签，保留原设置与历史分类。
- 展开播放页收起导航，以封面与歌词分列；浏览详情不自动播放。登录、搜索、队列、评论、确认框、添加歌单与歌曲资料使用同一玻璃材质和层级。
- 玻璃后景使用 SVG 位移滤镜；文字与按钮不参与扭曲。透镜图只在初始化和尺寸变化时生成，指针通过 CSS 变量调整高光。
- 背景跟随当前播放封面，加载完成后切换，过期加载被丢弃。无封面或失败时回到固定冷调背景。
- 银灰浅色、石墨深色及四种既有主题色继续可用。键盘进度条、封面操作、队列和添加歌单可用；公共弹窗有名称、初始焦点、Tab 圈定及关闭后的焦点返回。

## 自动检查与功能证据

使用已存在的 Node 24.19.0 执行 `npm run check`：lint 通过，8 个测试文件共 **64 项测试通过**，Vite 生产构建成功。改动前记录为 55 项测试通过；新增测试覆盖背景加载竞态、进度条键盘 seek、嵌套弹窗焦点，以及真实全局快捷键存在时歌词 Space 不重复触发播放。

浏览器批量验收使用公开音乐封面、标明验收用途的模拟用户/歌词、模拟 API 与静音 WAV。检查通过：

- 首页推荐顺序及首项不重复、搜索四类结果、播放详情不自动播放、进度 ArrowRight 从 17000ms 跳到 18000ms。
- 跨路由播放保持同一个音频源；嵌套浮层 Esc 只关闭栈顶。歌词及列表 Space 不冒泡重复切换播放。
- 搜索弹窗初始焦点、Tab 圈定、关闭后返回搜索框；队列键盘移除及焦点可见；歌单表单名称、焦点与 Esc。
- 通过实际设置控件选择深色/紫罗后刷新，主题和主题色恢复，播放仍处于暂停；隔离本地歌单可通过 Space 添加曲目，弹窗关闭后焦点返回“更多”。
- 两种主题 × 四种主题色，对当前重点播放按钮和活动导航项读取实际样式/背景像素，对比度分别为 5.03–10.08:1 和 4.82–7.63:1。该结果限定于这两类已检控件，不代表逐像素全站审计。
- 独立复核追加指出队列当前曲名的遗漏，最终使用正文色并保留选中底色。补测两主题 × 四色，邻近文字背景取样对比度为 6.93–10.18:1；原队列截图已更新。

## 浏览器、尺寸及降级

已在 Chrome、Edge 和实际 Electron 44.9.0 / Chromium 152 的隔离窗口检查渲染。常规浏览器截图覆盖 900×650、1280×820、1440×900，深浅主题及既有主题色；批量报告 20 张截图，无页面错误、横向溢出或已检查封面加载缺失。

Electron 通过既有桌面入口运行，独立用户目录，隐藏窗口原生 `capturePage` 截图。900×650 外窗对应 896×623 内容区，文档宽度 892px，无横向溢出；正常外窗 1280×820 对应内容区 1274×787。渲染进程未暴露 Node。此项验证源码入口，未重建或验证旧安装包的新视觉。

Chromium 的折射开关截图对比有 68231 个像素变化，表明位移确实影响后景。非 Chromium 模式使用磨砂；减少透明度时滤镜为 `none` 并使用实体表面；减少动态效果时停用追光与过渡。Safari/Firefox 真机未运行，降级检查使用受控浏览器环境。

短时空闲/滚动 rAF 探针各记录 119 帧，p95 约 6.2ms，未出现 >32ms 的间隔。该探针仅描述测试时本机环境，不能替代持续使用或人工流畅度验收。切歌背景竞态由单元测试覆盖，未把短时渲染观测表述为所有设备的帧率保证。

本地登录页 Lighthouse 两次采样：Performance 98 / 91，Accessibility 94 / 100，Best Practices 100 / 100。第二次在修正页面语言后采集，LCP 3.1s、TBT 40ms、CLS 0；性能采样受同机并行任务和节流影响，未建立改造前性能对照。未为提高评分改写业务流程或依赖。
