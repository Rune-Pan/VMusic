### 2) 项目背景

听潮（VMusic）是一个基于 Vue 3 框架的音乐 Web 单页应用。项目参考了 GitHub 开源项目 [YesPlayMusic](https://github.com/qier222/YesPlayMusic) 的架构设计理念，使用 GitHub 开源项目 [Binaryify/NeteaseCloudMusicApi](https://github.com/Binaryify/NeteaseCloudMusicApi)（网易云音乐第三方 API）作为后端数据源，实现了音乐发现、在线播放、歌单管理、用户个人中心等核心功能。项目采用 Vite 构建工具、Pinia 状态管理、Vue Router 路由控制、Howler.js 音频播放引擎，并结合 IndexedDB + SWR 缓存策略，打造了一个功能完善、用户体验良好的现代化音乐网站。

### 3) 需求分析

#### 功能需求

- **用户模块**：支持手机号+密码登录、手机号+验证码登录、二维码扫描登录三种方式；喜欢的歌曲管理
- **音乐发现**：首页推荐歌单、每日推荐（歌曲/歌单）、排行榜（官方榜/精选榜/全球榜）、分类筛选
- **音乐播放**：在线播放（Howler.js）、播放/暂停、上/下一首、进度控制、音量控制、循环模式（顺序/随机/单曲）、播放列表管理、歌词显示（含翻译同步）
- **歌单管理**：歌单详情查看、创建歌单、添加/移除歌曲、搜索歌曲
- **个人中心**：我的歌单、喜欢的歌曲、播放历史、个人设置（主题/主题色/音质/歌词字号/快捷键/预加载）
- **交互体验**：全局搜索、评论查看、歌曲详情弹窗、确认弹窗、Toast 通知、全局键盘快捷键

#### 非功能需求

- **性能**：IndexedDB 持久缓存 + SWR 策略 + LRU 淘汰，减少重复请求，提升页面加载速度
- **用户体验**：骨架屏加载态、空态提示、播放失败重试、试听权限提示

#### 组件划分原则

- **视图（Views）**：页面级组件，与路由一一对应，负责数据获取和页面布局
- **组件（Components）**：可复用 UI 单元，如 MusicCard、TrackList、PlayerBar 等
- **API 层**：按业务领域拆分，每个函数封装具体接口调用
- **Store**：按数据域划分，user/player/music/ui 各自职责单一
- **工具函数**：请求封装、通用工具、数据库操作分层管理

#### 代码规范

- ESLint + Oxlint 双 lint 体系，Prettier 格式化（无分号、单引号、行宽 100）
- 组件使用 `<script setup>` 语法，scoped 样式隔离
- 常量集中管理在 `constants.js`，避免硬编码散落
- API 响应统一通过 Axios 拦截器处理

### 5) 音乐账号登录页面组件代码设计

**组件路径**：`src/views/LoginView.vue`

**核心功能**：

1. **三种登录方式切换**：`activeTab` 响应式变量控制三种登录方式切换（'qrcode' / 'phone' / 'sms'），通过 Tab 标签页切换 UI 显示
2. **二维码登录**：调用 `loginQrCodeKey()` 获取二维码 key，使用 `qrcode` 库生成二维码图片，每 1 秒轮询 `loginQrCodeCheck()` 检查扫码状态，扫码成功后调用 `loginWithQrCode(cookie)` 注入 Cookie 并获取用户信息
3. **密码登录**：输入手机号和密码，调用 `loginWithPhone()` 接口，成功后保存用户信息到 localStorage
4. **验证码登录**：输入手机号，点击"发送验证码"按钮调用 `captchaSent()`，`countdown` 响应式变量控制 60 秒倒计时，输入验证码后调用 `loginWithCaptcha()` 完成登录
5. **主题切换**：页面右上角提供 Sun/Moon/Monitor 图标按钮，切换深色/浅色/跟随系统主题
6. **表单验证**：手机号格式正则校验（`/^1[3-9]\d{9}$/`）、密码长度校验（至少 6 位）、验证码非空校验
7. **路由跳转**：登录成功后跳转到 `redirect` 查询参数指定的页面，或默认首页 `/`

**二维码生成与轮询逻辑**（`src/views/LoginView.vue`）：

```javascript
// 获取二维码 key 并渲染 SVG
async function getQrCodeKey() {
  const result = await loginQrCodeKey()
  if (result.code === 200) {
    qrKey.value = result.data.unikey
    const svg = await QRCode.toString(
      `https://music.163.com/login?codekey=${qrKey.value}`,
      { width: 192, margin: 0, type: 'svg' }
    )
    qrCodeSvg.value = `data:image/svg+xml;utf8,${encodeURIComponent(svg)}`
    checkQrCodeLogin() // 启动轮询
  }
}

// 每 1 秒轮询扫码状态，状态码 800 过期/801 等待/802 已扫/803 成功
function checkQrCodeLogin() {
  clearQrCodeInterval()
  qrCodeCheckInterval = setInterval(async () => {
    const result = await loginQrCodeCheck(qrKey.value)
    if (result.code === 800) {        // 过期，重新生成
      clearQrCodeInterval()
      getQrCodeKey()
    } else if (result.code === 803) { // 登录成功，注入 cookie
      clearQrCodeInterval()
      await userStore.loginWithQrCode(result.cookie)
      router.push(route.query.redirect || '/')
    }
  }, 1000)
}
```

```javascript
// 账号长度校验（4-16 位）
function validateAccount() {
  if (!form.account) { errors.account = '请输入手机号'; return false }
  if (form.account.length < 4 || form.account.length > 16) {
    errors.account = '账号长度需为4-16位'; return false
  }
  errors.account = ''
  return true
}

// 提交：按凭证类型走密码或验证码登录
async function handleSubmit() {
  if (!validateAccount()) return
  if (credentialType.value === 'password') {
    if (!validatePassword()) return
    const success = await userStore.login({
      account: form.account, password: form.password
    })
    if (success) router.push(route.query.redirect || '/')
  } else {
    if (!validateCaptcha()) return
    const success = await userStore.loginWithCaptcha(form.account, form.captcha)
    if (success) router.push(route.query.redirect || '/')
  }
}
```

**组件路径**：`src/views/HomeView.vue`

**核心功能**：

1. **推荐歌单展示**：页面加载时调用 `musicStore.fetchRecommend()` 获取推荐歌单列表，使用 `MusicCard` 组件以 CSS Grid 网格布局展示

5. **卡片交互**：点击 `MusicCard` 使用 `<router-link>` 跳转到歌单详情页（`/playlist/:id`）
6. **数据缓存**：推荐数据和分类数据均通过 IndexedDB + SWR 策略缓存，减少重复请求

### 1) IndexedDB + SWR 持久缓存策略

参考上游 YesPlayMusic 架构，引入 Dexie（IndexedDB）作为持久缓存层，采用 SWR（stale-while-revalidate）模式 + LRU 淘汰策略。6 张缓存表分别管理歌词、歌曲详情、歌单详情、音频 URL、用户歌单、杂项数据，每张表带 TTL 过期时间和 LRU 条数上限淘汰机制。大幅减少重复 API 请求，提升页面加载速度和用户体验。

**核心特点**：

- **命中未过期缓存直接返回**，零延迟
- **缓存过期返回旧值同时后台静默刷新**，用户无感知
- **超限按 `lastAccess` 时间删除最久未访问记录**，控制 IndexedDB 体积
- **播放失败自动清除失效 URL 缓存并重试**，避免播放卡死

**6 张缓存表**：

| 表名 | 内容 | TTL | 上限 |
|------|------|-----|------|
| `lyric` | 解析后的歌词数组（含翻译匹配） | 7 天 | 500 条 |
| `trackDetail` | 歌曲详情 + privileges | 1 天 | 500 条 |
| `playlistDetail` | 歌单详情 + tracks + 订阅态 | 1 小时 | 100 条 |
| `trackSource` | 音频 URL（不存字节） | 30 分钟 | 200 条 |
| `userPlaylists` | 用户歌单列表 | 10 分钟 | 5 条 |
| `miscCache` | 低频 GET 收口（toplists/categoryList/recommend/评论） | 可变 | 可变 |

**db.js 中 SWR 封装与 LRU 淘汰**（`src/utils/db.js`）：

```javascript
// LRU 淘汰：按 lastAccess 升序删最旧，直到条数 <= max
async function evictIfNeeded(table, max) {
  const count = await db[table].count()
  if (count <= max) return
  const overflow = count - max
  const oldest = await db[table].orderBy('lastAccess').limit(overflow).toArray()
  await db[table].bulkDelete(oldest.map(r => r.id))
}

// 判断是否过期
function isStale(updateTime, ttl) {
  return Date.now() - updateTime > ttl
}

// 缓存写入：put + LRU 淘汰
export async function cacheLyric(id, lyric) {
  await db.lyric.put({ id, lyric, updateTime: Date.now(), lastAccess: Date.now() })
  await evictIfNeeded('lyric', CACHE_MAX_LYRIC)
}

// 读取：命中更新 lastAccess，返回数据 + stale 标志
export async function getLyricFromCache(id) {
  const record = await db.lyric.get(id)
  if (!record) return null
  await db.lyric.update(id, { lastAccess: Date.now() })
  return { lyric: record.lyric, stale: isStale(record.updateTime, CACHE_TTL_LYRIC) }
}
```

```javascript
let installed = false
function onKeydown(e) {
  if (!enabled.value) return
  // input/textarea 聚焦时跳过，避免打字误触
  if (isInputFocused()) return
  // Space 且焦点是按钮时跳过，避免误触发按钮 click
  if (e.key === ' ' && document.activeElement?.tagName === 'BUTTON') return

  const playerStore = usePlayerStore()
  const uiStore = useUiStore()

  for (const action of SHORTCUT_ACTIONS) {
    if (!matchShortcut(action, e)) continue
    e.preventDefault()
    switch (action.id) {
      case 'playPause': playerStore.togglePlay(); break
      case 'prev': playerStore.prev(); break
      case 'next': playerStore.next(); break
      case 'volumeUp':
        playerStore.setVolume(Math.min(1, playerStore.volume + SHORTCUT_VOLUME_STEP))
        break
      case 'volumeDown':
        playerStore.setVolume(Math.max(0, playerStore.volume - SHORTCUT_VOLUME_STEP))
        break
      case 'mute': playerStore.toggleMute(); break
      case 'like': toggleLike(playerStore, uiStore); break
    }
    return
  }
}
```

```javascript
// 根据当前深浅模式，把 preset 的 5 个 CSS 变量写到 :root
function applyThemeColor(colorValue, appearance) {
  const preset =
    THEME_COLOR_OPTIONS.find(o => o.value === colorValue) ||
    THEME_COLOR_OPTIONS[0]
  const resolvedAppearance =
    appearance ||
    (theme.value === 'auto' ? systemTheme.value : theme.value)
  const palette = preset[resolvedAppearance] || preset.light
  const root = document.documentElement
  root.style.setProperty('--color-primary', palette.primary)
  root.style.setProperty('--color-primary-hover', palette.primaryHover)
  root.style.setProperty('--color-primary-bg', palette.primaryBg)
  root.style.setProperty('--color-primary-bg-transparent', palette.primaryBgTransparent)
  root.style.setProperty('--shadow-glow', palette.shadowGlow)
}

// 监听系统深浅模式变化
const mediaQuery = window.matchMedia?.(SYSTEM_DARK_QUERY)
mediaQuery?.addEventListener('change', onSystemChange)

// 深浅切换时联动重应用主题色（dark 配色明度不同）
watch(effectiveTheme, newVal => {

})
```

```javascript
export async function runPreload() {
  const cfg = config.value
  if (!cfg.enabled || !cfg.items) return
  const userStore = useUserStore()
  if (!userStore.isLoggedIn || !userStore.userInfo.id) return
  const musicStore = useMusicStore()

  // 各项独立 catch，互不影响，一项失败不影响其他项
  const tasks = []
  if (cfg.items.dailyRecommend) {
    tasks.push(musicStore.fetchDailyRecommend().catch(() => {}))
  }
  if (cfg.items.toplists) {
    tasks.push(musicStore.fetchToplists().catch(() => {}))
  }
  if (cfg.items.liked) {
    tasks.push(userStore.fetchLikedTracks().catch(() => {}))
  }
  if (cfg.items.playlists) {
    tasks.push(
      userPlaylist({ uid: userStore.userInfo.id, limit: 50 }).catch(() => {})
    )
  }
  await Promise.allSettled(tasks)
}
```

### 6) 三种登录方式集成

集成了手机号+密码、手机号+验证码、二维码扫描三种登录方式。二维码登录使用 `qrcode` 库生成图片，每 1 秒轮询检查扫码状态，支持二维码过期自动刷新。验证码登录集成 60 秒倒计时功能。

**三种登录方式对比**：

### 7) 歌词同步与翻译支持

实现了 LRC 歌词解析器（`parseLRC` 工具函数），支持带翻译的歌词匹配。使用 `setInterval` 每 100ms 轮询播放进度，自动高亮当前歌词行并平滑滚动到可视区域。支持显示/隐藏翻译歌词的开关和歌词字号设置。

**关键实现**：

```javascript
// common.js 中的 LRC 解析
function parseLRC(lrcText) {
  const lines = lrcText.split('\n')
  const result = []
  const timeRegex = /\[(\d{2}):(\d{2})\.(\d{2,3})\](.*)/
  for (const line of lines) {
    const match = line.match(timeRegex)
    if (match) {
      const minutes = parseInt(match[1])
      const seconds = parseInt(match[2])
      const milliseconds = parseInt(match[3].padEnd(3, '0'))
      const time = minutes * 60 * 1000 + seconds * 1000 + milliseconds
      result.push({ time, rawTime: match[0], content: match[4].trim() })
    }
  }
  return result
}
```

**parseLRC 工具函数**（`src/utils/common.js`）：

```javascript
export function parseLRC(lrcText) {
  if (!lrcText || typeof lrcText !== 'string') return []

  const lines = lrcText.split('\n')
  const result = []
  const timeRegex = /\[(\d{2}):(\d{2})\.(\d{2,3})\]/

  for (const line of lines) {
    const match = line.match(timeRegex)
    if (!match) continue

    const min = parseInt(match[1], 10)
    const sec = parseInt(match[2], 10)
    const ms = parseInt(match[3], 10)
    // 毫秒位 2 位按百分秒处理，3 位按毫秒处理
    const time = min * 60 + sec + ms / (match[3].length === 2 ? 100 : 1000)

    const content = line.replace(timeRegex, '').trim()
    if (content) {
      result.push({ time, rawTime: match[0], content })
    }
  }

  return result.sort((a, b) => a.time - b.time)
}
```

### 3) 注意事项

**潜在风险与解决方案**：

1. **网易云 API 服务未启动**：
   - **症状**：页面请求失败，无法加载数据
   - **解决方案**：确保本地 API 服务正在运行（`node app.js` 或 npx 命令），检查 `localhost:3000` 是否可访问

2. **网络请求超时**：
   - **症状**：加载数据失败，显示错误提示
   - **解决方案**：检查网络连接，Axios 超时设置为 15 秒，可适当调整 `request.js` 中的 `timeout` 配置

3. **二维码登录失败**：
   - **症状**：二维码过期或扫码后无响应
   - **解决方案**：等待二维码自动刷新，确保网易云 APP 已登录且网络正常

4. **歌曲无法播放**：
   - **症状**：点击播放无声音或提示"暂无播放权限"
   - **解决方案**：部分歌曲需要 VIP 权限，系统会提示试听；检查音频 URL 是否失效，可尝试清除缓存（切换音质或重新登录）

5. **缓存数据过期**：
   - **症状**：显示的数据不是最新的
   - **解决方案**：SWR 策略会在后台静默刷新，等待几秒即可；或刷新页面强制更新

6. **浏览器兼容性**：
   - **症状**：某些功能在旧版浏览器中异常
   - **解决方案**：项目使用现代浏览器 API（IndexedDB、CSS 变量、Proxy 等），建议使用 Chrome、Firefox、Edge 等现代浏览器

7. **移动端适配说明**：
   - **说明**：项目当前保留移动端基础适配，后续将移除移动端适配，专注于桌面端体验优化
   - **建议**：优先使用桌面浏览器访问以获得最佳体验

8. **localStorage 空间限制**：
   - **症状**：浏览器存储空间不足
   - **解决方案**：IndexedDB 有 LRU 淘汰机制，自动清理过期和最少访问的数据，一般不会超出限制

9. **HTTPS 环境要求**：
   - **说明**：生产环境部署时需要 HTTPS，否则 Cookie 携带和音频播放可能受限
   - **解决方案**：配置 `.env.production` 中的 `VITE_NETEASE_API_URL` 为 HTTPS 地址
