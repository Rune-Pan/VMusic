# 听潮功能状态与验收

[项目 README](../README.md) · [开发指南](./开发指南.md)

当前功能以源码和页面入口为准；“已接入”表示存在实现，不代表所有环境已验收。
主要能力见 [README](../README.md#功能)，本页只保留功能边界与检查方法。

## 功能边界

| 能力 | 当前状态 |
| --- | --- |
| 登录 | 扫码、手机号密码、验证码；使用已有网易云账号 |
| 歌单管理 | 有创建、添加和本地移除；没有歌单编辑、删除入口 |
| 收藏歌单 | 展示账号已有收藏；没有收藏、取消收藏按钮 |
| 个人资料 | 展示账号资料；没有昵称、头像编辑入口 |
| 专辑 | 搜索与歌手专辑列表可用；没有独立专辑详情页 |
| 评论 | 歌曲、歌单评论只读查看与分页；没有发表入口 |
| 注册、邮箱登录、私人 FM、MV | 当前不提供 |
| 浏览与音频 | 主要面向桌面；音频由上游 URL 播放，不提供离线播放 |

删除歌单和修改资料保留了底层函数，不能因此在功能介绍中写成可用操作。
实际音频、完整播放或试听、可选音质取决于上游服务及账号权限。
歌曲权限限制由 `mapTrackPlayableStatus()` 和播放 URL 响应共同决定。
歌词为 LRC 行级同步，翻译须存在匹配内容；歌词设置按页面提示重新进入后生效。

## 数据写入边界

| 操作 | 数据去向与限制 |
| --- | --- |
| 创建歌单 | 名称和隐私参数提交网易云；简介只保存本地 |
| 添加到本地歌单 | 更新当前浏览器记录，不同步网易云 |
| 添加到网易云歌单 | 请求 `/playlist/tracks`，以服务端响应和权限为准 |
| 从自己的歌单移除歌曲 | 更新当前列表、缓存和本地记录，没有请求云端删除 |
| 编辑歌单信息的底层函数 | 仅修改本地记录，没有服务端编辑入口 |
| 喜欢、取消喜欢 | 请求网易云接口并维护本地喜欢列表 |
| 清空播放历史 | 仅清理本地历史，不删除最近一周或全部时间的服务端历史 |
| 主题、快捷键、歌词及预加载偏好 | 当前浏览器持久化，不代表跨设备同步 |

本地副本可能与网易云内容不同。操作提示和本地列表更新不保证云端已同步。
退出登录会清理用户状态和音频 URL 缓存，不清空所有个人偏好。
相关实现见 [music Store](../src/stores/music.js)、[ProfileView](../src/views/ProfileView.vue)、
[PlaylistView](../src/views/PlaylistView.vue) 和 [AddToPlaylistModal](../src/components/AddToPlaylistModal.vue)。

## 已知问题与待验证事项

- 真实账号的三种登录、刷新后会话恢复、实际音频播放需要在目标环境验收。
- 创建、添加歌单应使用测试歌单，分别核对本地与网易云结果。
- `/playlist/subscribe` 过去曾返回 405，前端随后移除了收藏操作。
- 该历史现象尚未确定唯一原因；恢复功能前需重新记录环境、参数和响应。
- 歌单缓存或列表可能短时滞后，不能把本地即时变化描述为所有页面同步。
- 全仓库 lint 包含第三方后端的存量报错；构建通过不等于 lint 全部通过。

排障先记录请求路径、参数、HTTP 状态、响应 `code`、账号权限和缓存命中情况。
缓存返回的业务字段可能与网络响应不同，诊断步骤见[开发指南](./开发指南.md#本地排障)。

## 手工验收

以下是检查清单，尚未勾选的项目不表示已通过。
执行时记录日期、浏览器、运行环境、账号权限、预期与实际结果。

- [x] **启动与代理**：同时启动两端，直连后端和 `/api` 歌曲详情均返回有效 JSON。
- [ ] **路由权限**：未登录访问个人中心跳登录页，登录后返回原路径。
- [ ] **三种登录**：分别扫码、密码、验证码登录，核对成功、失败和过期反馈。
- [ ] **会话恢复**：登录后刷新并请求账号接口，确认页面标记与服务端会话一致。
- [ ] **发现与搜索**：切换分类，搜索四种类型，歌手结果可进入详情。
- [ ] **详情与分页**：歌单继续加载曲目，歌手歌曲及专辑分页不重复、不遗漏。
- [ ] **页面刷新**：直接访问或刷新歌单、歌手子路径，按登录状态正常导航。
- [ ] **共享播放**：播放、暂停、切歌、拖动进度，页面切换保持同一播放器。
- [ ] **音量与队列**：取消静音恢复音量，队列删空后停止音频及进度计时。
- [ ] **试听与失败**：试听提示与实际时长一致，失效 URL 最多清缓存重取一次。
- [ ] **歌词**：高亮与播放同步，点击可跳转，翻译与偏好按提示生效。
- [ ] **歌单写入**：用测试歌单创建和添加，分别检查本地记录与网易云端内容。
- [ ] **本地移除**：列表和本地记录变化，不宣称云端歌曲已删除。
- [ ] **喜欢与历史**：喜欢状态刷新后保留，清空本地历史不影响服务端历史。
- [ ] **偏好设置**：主题、快捷键、预加载刷新后恢复，键位冲突有反馈。
- [ ] **弹窗与输入**：ESC 只关栈顶，取消确认不执行操作，输入框不被快捷键干扰。
- [ ] **部署**：公开 API、子路径刷新、真实登录和实际播放逐项记录结果。

验证记录必须区分以下层次：

| 层次 | 能证明什么 |
| --- | --- |
| 源码检查 | 有入口、逻辑或保护机制 |
| lint 与构建 | 代码检查结果和静态资源可生成 |
| 后端及开发代理检查 | 公开接口和本地请求链路可用 |
| 真人账号操作 | 对应环境和账号下的登录、播放或写入行为 |

根项目没有 `npm test`。构建使用 `npm run build`，接口检查见开发指南。
公开接口返回成功不能替代真人登录、实际播放或歌单写入验证。
尚未执行的真人检查继续保留待验收状态，不能用未勾选清单冒充测试结果。
