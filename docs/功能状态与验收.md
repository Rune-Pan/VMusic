# 听潮功能状态与验收

[项目 README](../README.md) · [开发指南](./开发指南.md)

当前功能以源码和页面入口为准；“已接入”表示存在实现，不代表所有环境已验收。
主要能力见 [README](../README.md#功能)，本页只保留功能边界与检查方法。

## 功能边界

| 能力 | 当前状态 |
| --- | --- |
| 登录 | 扫码、手机号密码、验证码；恢复时校验服务端会话，失效保留原路径；网络失败可重试 |
| 歌单管理 | 新建私密云歌单、名称与简介编辑、删除本人普通歌单、云端增删歌曲；删除/移除须确认 |
| 收藏歌单 | 他人歌单详情提供收藏/取消收藏；以服务端业务结果为准 |
| 个人资料 | 展示账号资料；没有昵称、头像编辑入口 |
| 专辑 | 搜索与歌手页可进入受登录保护的详情，展示元数据、可展开简介及完整曲目；支持单曲、下一首、喜欢和播放全部；没有专辑收藏、评论或播放器专辑文本入口 |
| 评论 | 歌曲、歌单只读评论支持最新、最热、推荐排序，首次默认最新并共享本机偏好；触底分页、去重及失败重试，没有发表入口 |
| 注册、邮箱登录、私人 FM、MV | 当前不提供 |
| 浏览与音频 | 主要面向桌面；音频由上游 URL 播放，不提供离线播放 |
| 搜索 | 四类独立分页，每页16条；去重、结束状态、错误重试，旧请求不覆盖新搜索；从专辑后退到来源历史项可恢复关键词、专辑标签、列表、滚动与焦点 |
| 本机历史歌单 | 个人中心独立只读分组，可查看/播放；不编辑、不删除、不自动上传 |

修改个人资料目前仅保留底层函数，没有可用的编辑入口；歌单操作已按下表接入。
实际音频、完整播放或试听、可选音质取决于上游服务及账号权限。
歌曲权限限制由 `mapTrackPlayableStatus()` 和播放 URL 响应共同决定。
歌词为 LRC 行级同步，翻译须存在匹配内容；字号、翻译与时间设置需重新进入播放页生效。
个人设置 → 播放与歌词 → 歌词颜色可独立设置当前行与普通行，翻译与时间继承所在行颜色。
支持跟随主题、六种预设、原生取色器及 `#RRGGBB` 输入，即时预览并自动保存到本机；
非法、未完成或过长输入保留上一有效色并提示，可逐项或全部恢复默认。
自定义色在深浅主题间保持固定，悬停不覆盖；可读性提示不强制改色。

## 数据写入边界

| 操作 | 数据去向与限制 |
| --- | --- |
| 创建歌单 | 默认私密，名称与简介提交网易云；简介失败保留已创建ID，重试不重复创建 |
| 本机历史歌单 | 保留原始记录，只读查看与播放，不再作为添加目标 |
| 添加到网易云歌单 | 仅显示本人普通歌单；解析嵌套业务响应，失败不假成功 |
| 从自己的歌单移除歌曲 | 确认后请求云端删除；成功后刷新详情与列表，失败保留内容 |
| 编辑、删除、收藏歌单 | 通过云端端点写入并刷新缓存；分步编辑可能部分成功，页面保留重试信息 |
| 喜欢、取消喜欢 | 请求网易云接口并维护本地喜欢列表 |
| 清空播放历史 | 仅清理本地历史，不删除最近一周或全部时间的服务端历史 |
| 主题、快捷键、歌词、评论排序及预加载偏好 | 当前浏览器持久化，不代表跨设备同步 |

历史本地副本可能与网易云不同，不自动合并。云端操作仅在业务响应成功后提示成功；缓存刷新失败单独提供重新加载。
退出登录停止音频、加载任务与连播，保存暂停队列及位置；作废账号相关旧请求并清理音源URL缓存，不清空个人偏好或本机历史。
相关实现见 [music Store](../src/stores/music.js)、[ProfileView](../src/views/ProfileView.vue)、
[PlaylistView](../src/views/PlaylistView.vue) 和 [AddToPlaylistModal](../src/components/AddToPlaylistModal.vue)。

## 已知问题与待验证事项

- 三种登录方式、不同账号权限及目标部署需要分别验收；本机当前账号的复验见下文。
- 首页歌单封面的快捷播放已修复，代码与回归检查见下文“首页歌单快捷播放修复”。
- 创建、添加歌单应使用测试歌单，分别核对本地与网易云结果。
- `/playlist/subscribe` 过去曾返回405。当前已恢复入口并提供业务错误反馈；本轮真实账号未对他人歌单执行收藏/取消，成功与405场景均有隔离模拟覆盖。
- 云写入后使相关缓存失效并刷新共享列表及打开的详情；刷新网络失败仍需点击重新加载，不能把成功提示当作所有设备同步完成。
- 全仓库 lint 包含第三方后端的存量报错；构建通过不等于 lint 全部通过。

排障先记录请求路径、参数、HTTP 状态、响应 `code`、账号权限和缓存命中情况。
缓存返回的业务字段可能与网络响应不同，诊断步骤见[开发指南](./开发指南.md#本地排障)。

验证记录必须区分以下层次：

| 层次 | 能证明什么 |
| --- | --- |
| 源码检查 | 有入口、逻辑或保护机制 |
| lint 与构建 | 代码检查结果和静态资源可生成 |
| 后端及开发代理检查 | 公开接口和本地请求链路可用 |
