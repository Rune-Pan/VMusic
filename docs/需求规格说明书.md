## 项目目标与范围

项目面向使用桌面浏览器的网易云音乐账号用户，提供音乐发现、播放、
歌单浏览与个人音乐管理，同时展示 Vue 组件化、路由、状态管理和接口协作。

游客只能访问登录页。登录后访问推荐、歌单、播放、个人中心、每日推荐、
排行榜和歌手页。音乐数据来自第三方网易云 API，账号权限与接口状态影响实际结果。

当前范围包括前端界面、仓库内后端接入和 Vercel 部署入口，
不设计独立账号体系、后台管理系统或音频下载服务。

## 术语

| 术语        | 本项目中的含义                                             |
| ----------- | ---------------------------------------------------------- |
| SPA         | 页面切换由 Vue Router 完成，服务端需为页面路径提供入口回退 |
| Pinia Store | 用户、播放、内容和界面四个全局状态域                       |
| 本地记录    | 仅保存在当前浏览器的 localStorage 或 IndexedDB 数据        |
| 服务端数据  | 通过网易云 API 请求得到或写入的账号数据                    |
| SWR         | 缓存过期后先使用旧数据，同时后台请求更新                   |
| LRU         | 达到记录数上限时，淘汰最少访问的缓存记录                   |
| 已实现      | 当前页面有入口与相应处理逻辑，仍需实际环境验收             |

## 功能需求

沿用 `FUN-模块-序号` 的主要编号。保留但未实现的原需求明确标记，
后续新增需求使用未占用的序号，不将课程题目示例视为已完成能力。

### 用户认证（FUN-USER）

| 编号         | 需求与验收条件                                                                 | 当前状态                   |
| ------------ | ------------------------------------------------------------------------------ | -------------------------- |
| FUN-USER-001 | 支持扫码、手机号密码和验证码登录；显示校验和请求反馈；成功后返回目标页面或首页 | 已接入，真人登录待验收     |
| FUN-USER-002 | 原账号注册需求                                                                 | 未实现，使用已有网易云账号 |
| FUN-USER-003 | 未登录访问受保护页面跳登录页并保留原路径；已登录访问登录页回首页               | 已实现                     |

登录标记恢复不代表服务端会话永久有效。退出登录应清理用户状态，
避免继续展示已登录身份；音频 URL 缓存同时清理。

### 播放与歌词（FUN-PLAYER）

| 编号           | 需求与验收条件                                         | 当前状态 |
| -------------- | ------------------------------------------------------ | -------- |
| FUN-PLAYER-001 | 显示封面、歌曲、歌手和专辑信息；页面切换时共用播放器   | 已实现   |
| FUN-PLAYER-002 | 解析 LRC，随进度高亮和滚动；有匹配翻译时按设置显示     | 已实现   |
| FUN-PLAYER-003 | 支持播放暂停、上下首、循环与随机、音量、静音、播放队列 | 已实现   |
| FUN-PLAYER-004 | 进度显示与拖动同步；试听使用实际音频时长               | 已实现   |

歌曲是否可播依据 `mapTrackPlayableStatus()` 与音频响应。
无版权和需购买歌曲限制点击；VIP 歌曲可能只能试听，实际 URL 由上游决定。
音频加载失败后最多清缓存并重试一次。不承诺所有歌曲可完整播放。

## 非功能要求

| 类别     | 要求与边界                                                         |
| -------- | ------------------------------------------------------------------ |
| 工程组织 | Vue 3 + Vite；页面、组件、Store、API、工具层职责明确               |
| 浏览环境 | 使用支持 IndexedDB 和现代 Web API 的桌面浏览器；兼容性以实测为准   |
| 加载体验 | 缓存与按需预加载减少重复请求，不设未测量的“秒开”或固定响应时间承诺 |
| 缓存     | 数据有 TTL 与 LRU 条数上限；只保存音频 URL，不提供离线音频         |
| 主题     | 浅色、深色、跟随系统与四种主题色保持主要页面一致                   |
| 操作反馈 | 能区分请求中、空内容、失败与试听状态                               |
| 部署     | 前后端同域 `/api`，页面子路径刷新可以返回前端入口                  |
| 维护     | 常量集中，视图单根；依赖与格式以配置文件为准                       |

## 验收清单

以下是待执行或复核的手工检查步骤，不是自动化测试结果。
记录日期、浏览器、运行环境、账号权限和实际结论。

| 场景       | 操作                                       | 预期                                           |
| ---------- | ------------------------------------------ | ---------------------------------------------- |
| 启动与代理 | 同时启动两端，请求公开歌曲详情             | 后端与 `/api` 代理均返回有效 JSON              |
| 路由权限   | 清除登录标记后访问个人中心，完成登录       | 先跳登录并保留目标路径，成功后回跳             |
| 三种登录   | 分别扫码、密码、验证码登录                 | 正确展示请求状态和失败原因；成功后读取账号资料 |
| 发现与搜索 | 切换分类，搜索四种类型，点击歌手结果       | 结果与类型匹配，歌手详情可打开                 |
| 页面刷新   | 直接访问或刷新歌单 / 歌手路径              | 返回前端入口，按登录状态导航                   |
| 播放       | 播放有权限歌曲，暂停、切歌、拖动、静音     | 状态与音频一致，取消静音恢复音量               |
| 试听与失败 | 播放仅有试听权限的歌曲或失效 URL           | 显示试听提示，失败重试有次数边界               |
| 歌词       | 播放有翻译歌词的歌曲并调整偏好             | 高亮同步；设置按提示在重新进入后生效           |
| 歌单写入   | 使用测试歌单创建和添加，检查网易云端结果   | 区分本地与服务端操作，不把本地变化当成同步成功 |
| 本地移除   | 在自己的歌单中移除歌曲                     | 当前列表与本地记录变化；不宣称云端已删除       |
| 偏好与历史 | 改主题、快捷键与预加载后刷新，清空本地历史 | 偏好恢复，服务端历史不因本地清空而被删除       |
| 弹窗与输入 | 取消确认、关闭弹窗，在输入框中按快捷键     | 取消不执行操作，输入不被快捷键干扰             |

构建检查使用 `npm run build`。根项目没有自动化测试套件，
`npm run lint` 会自动修复且可能报告第三方后端的存量问题，应单独记录。
